# FaceCatch - 人脸抓取应用

这是一个基于Android平台的人脸抓取应用，使用CameraX和ML Kit实现人脸识别与抓取功能。

## 功能特性

1. **实时摄像头预览** - 提供流畅的实时摄像头画面预览
2. **人脸检测** - 使用ML Kit进行实时人脸检测
3. **可视化标记** - 在检测到的人脸周围显示绿色矩形框
4. **头部区域覆盖** - 框选区域扩展以包含完整头部区域
5. **实时跟踪** - 绿色框跟随人脸移动实时调整位置
6. **人脸抓取** - 点击按钮保存当前人脸区域照片
7. **优化性能** - 高效的图像处理和流畅的用户体验

## 技术栈

- **CameraX** - 现代化的相机开发库
- **ML Kit Face Detection** - Google的人脸检测API
- **Kotlin** - 主要开发语言
- **AndroidX** - 现代Android开发库

## 权限要求

- `CAMERA` - 访问设备摄像头

## 使用方法

1. 启动应用并授予相机权限
2. 应用将显示实时摄像头预览
3. 当检测到人脸时，会显示绿色矩形框标记
4. 点击底部的相机按钮进行人脸抓取
5. 抓取的照片将保存到应用的图片目录

## 代码结构

- `MainActivity.kt` - 主活动，处理相机和UI逻辑
- `FaceDetectionAnalyzer.kt` - 人脸检测分析器
- `OverlayView.kt` - 自定义视图，用于绘制人脸框
- `ImageUtils.kt` - 图像处理工具类

## 性能优化

- 使用STRATEGY_KEEP_ONLY_LATEST策略减少延迟
- 启用跟踪模式提高检测性能
- 优化图像处理流程
- 使用抗锯齿绘制平滑的检测框
